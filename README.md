# AB Kitchen

Отдельная копия существующих кухонных разделов back-office
[`krupchanskiy/srsk`](https://github.com/krupchanskiy/srsk), переименованная в
**AB Kitchen**.

В копию входят только уже существующие разделы:

- меню, планировщик и шаблоны меню;
- рецептуры и продукты;
- заявки на закупку и приёмка;
- склад, остатки, выдачи и инвентаризации;
- команда;
- кухонные справочники;
- авторизация, роли и права пользователей.

Новый функционал не добавлялся. Дизайн и рабочие сценарии исходных страниц
сохранены. CRM, размещение, финансы, фотографии и другие разделы back-office
в этот проект не входят.

## Изоляция

Этот репозиторий не должен подключаться к рабочей базе исходного back-office.
Приложение подключено только к отдельному проекту Supabase AB Kitchen.

Во фронтенд передаются только публичные `SUPABASE_URL` и
`SUPABASE_ANON_KEY`. Административные ключи и пароли базы нельзя помещать в
этот файл или коммитить в репозиторий.

Кухонная схема и роли находятся в каталоге `supabase`. CRM, размещение,
финансы и фотографии в новую базу не переносятся.

## GitHub Pages

Production-сборка публикуется из ветки `main` по адресу:

<https://sri-rupa-seva-kunj.github.io/ab-kitchen/>

Workflow передаёт в Pages только статические файлы приложения. SQL-миграции
и служебные файлы в опубликованный сайт не попадают.

## Локальный просмотр

Приложение статическое. После заполнения конфигурации его можно открыть любым
HTTP-сервером из корня проекта, например:

```bash
npx serve .
```
